# sudoku-solver
Solver for sudoku and killer sudoku using human-style methods. As of Feb 2026, this is the best publicly available solver for killer sudoku using human-style methods.

Test:
```
python3 -m unittest discover
```

## Grading

A puzzle's grade is based on how long it takes the solver to solve the puzzle.

First, calibration is done on a simple, open-source puzzle. This puzzle is by definition grade 1.

Next, the puzzle given to the solver is solved, with the time taken for each step measured.

$$Step\ score = 100 * \frac{Time\ to\ make\ step}{Time\ to\ solve\ calibration\ puzzle}$$

While step scores are not used in the final grade, they're used to convey how complex a given step was to make.

Finally, a final grade is rendered:

$$ f = \frac{Time\ to\ solve\ puzzle}{Time\ to\ solve\ calibration\ puzzle}$$

$$Puzzle\ grade = 
\begin{cases}
f & \text{if } f < 1 \\
1 + log_{2}(f) & \text{otherwise}
\end{cases}$$

These grades roughly correspond to the following:
- 1: Easy
- 2: Medium
- 3: Hard
- 4: Expert
- 5+: Beyond Expert

The hardest grade puzzle this solver can solve is approximately 6.
